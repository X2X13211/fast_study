Интерфейс представляет собой контракт, который обе стороны при взаимодействии обязуются соблюдать. Например, если в спецификации смартфона указано, что он поддерживает интерфейс USB Type-C, то для подключения к нему вы можете использовать соответствующий кабель. Применительно к языкам программирования, в частности к C#, интерфейс определяет набор методов, свойств и событий, которые класс, его реализующий, обязуется представить.

Спецификация на интерфейс позволяет нам понять какие операции мы можем выполнять с экземплярами соответствующих типов. Например, если класс реализует интерфейс `IEquatable<T>`, значит мы можем вызывать у его объектов метод `Equals` для сравнения на равенство.

```cs
public interface IEquatable<T>
{
    bool Equals(T? other);
}
```

# Объявление интерфейса

Для объявления интерфейса используется ключевое слово `interface`, после которого следует его имя.

Посмотрим на интерфейс `IEquatable<T>` из BCL .NET ещё раз.

```cs
public interface IEquatable<T>
{
    bool Equals(T? other);
}
```

Это обобщенный интерфейс (про обобщения мы поговорим в нашем курсе немного позже), который содержит всего один метод. Модификатор доступа для членов интерфейсов по умолчанию: `public`. Реализация интерфейса содержится в классах, имена интерфейсов перечисляются через двоеточие после имени класса, также как при наследовании от класса. Для того, чтобы класс мог представляться типом `IEquatable`, он должен его реализовать.

Внутри интерфейса мы можем объявлять:

- методы экземпляра;
- свойства;
- события;
- статические поля, свойства и методы.

Имя интерфейса, по соглашению об именовании в C#, должно начинаться с буквы `I` (это правило компилятор не проверяет).

```cs
interface IMyCustomInterface
{
    void Method(); // метод
    int Property { get; set; } // свойство

    static void StaticMethod() { } // статический метод
    static int StaticProperty { get; set; } // статическое свойство
    static int StaticField; // статическое поле
}
```

В интерфейсе нельзя создавать экземплярные поля. Если вы создаете статическое свойство, то для него нужно представить реализацию.
