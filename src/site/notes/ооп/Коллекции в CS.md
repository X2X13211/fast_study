**Коллекции** - это структуры данных для хранения наборов объектов. С одним из самых простых типов коллекций вы уже познакомились - это массивы. Среди коллекций выделяют индексируемые, к их элементам можно получить доступ по индексу (в качестве примера можно привести уже знакомые нам массивы), и коллекции пар "ключ"-"значение". Примером такой коллекции является словарь. Есть коллекции, в которых нет возможности обратиться к элементу напрямую, для доступа используется последовательный обход содержимого. В качестве примера такого решения можно привести связный список.

Язык C# предоставляет большое количество различных видов коллекций, а также ряд интерфейсов для сравнения элементов между собой, обхода элементов коллекций и т.д. В рамках данного урока мы познакомимся со следующими коллекциями:

- Динамический массив `List<T>`.
- Словарь (ассоциативный массив) `Dictionary<TKey, TValue>`.
- Стек `Stack<T>`.
- Множество `HashSet<T>`.
- Очередь `Queue<T>`.

При работе с коллекциями, как правило, выполняется два вида операций - это доступ к конкретному экземпляру и обход элементов коллекции. Для реализации второй задачи используется паттерн "Итератор", который в C# реализован определенным образом. В коллекциях, которые представлены в рамках стандартной библиотеки, итератор уже встроен, но может возникнуть ситуация, когда нужно разработать некоторую пользовательскую коллекцию, которая бы поддерживала обход элементов стандартным для C# образом. О том, как устроен итератор в C# и как его встроить в свои решения, мы поговорим в конце этого урока, а пока перейдем к обзору коллекций.
