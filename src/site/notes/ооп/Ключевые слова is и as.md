Как мы выяснили на предыдущем степе, если попытаться привести переменную одного типа к другому, который окажется для неё  неподходящим, то будет выброшено исключение. В этом случае наше приложение может аварийно завершиться.

Чтобы сделать этот процесс более безопасным и контролируемым можно использовать ключевые слова `is` и `as`.

Ключевое слово `is` позволяет проверить, соответствует ли тип переменной указанному. Если соответствует, то в результате вычисления выражения получаем `true`, иначе - `false`. С этим оператором мы с вами уже сталкивались, когда проходили условные выражения в модуле 3.

Перед тем как делать приведение типов, можно проверить, допустима эта операция или нет.

```cs
B b1 = new B();
A a1 = b1;

Console.WriteLine(a1 is A); // True
Console.WriteLine(a1 is B); // True

A a2 = new A();
Console.WriteLine(a2 is A); // True
Console.WriteLine(a2 is B); // False
```

Для приведения можно воспользоваться оператором `as`. В отличие от явного приведения, которое в случае неудачи выбрасывает исключение, `as` возвратит `null`.

```cs
B b1 = new B();
A a1 = b1;

B? b2 = a1 as B;
Console.WriteLine(b2 is null); // False

A a2 = new A();
B? b3 = a2 as B;
Console.WriteLine(b3 is null); // True
```
