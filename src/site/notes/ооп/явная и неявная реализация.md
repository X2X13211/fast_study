# Явная и неявная реализация

---
dg-publish: true
---



Как правило, при реализации интерфейса, используется неявный вариант.

```cs
interface IPrinter
{
    void PrintToConsole(string msg);
}

class MyPrinter: IPrinter
{
    public void PrintToConsole(string msg) =>    
        Console.WriteLine(msg);    
}
```

В этом случае, при работе с объектами класса, методами интерфейса можно пользоваться как методами самого класса.

```cs
var mp = new MyPrinter();
mp.PrintToConsole("Hello!"); // Hello

var printer = (IPrinter)mp;
printer.PrintToConsole("Test printer"); // Test printer
```

Интерфейс можно реализовать явно. Для этого нужно создать в соответствующем классе набор приватных методов, имена которых должны быть составлены по шаблону: `ИмяИнтерфейса.ИмяМетода`.

Реализуем явно `IPrinter`.

```cs
class MyPrinterExplicit : IPrinter
{
    void IPrinter.PrintToConsole(string msg) =>
        Console.WriteLine(msg);
}
```

При работе с такой реализацией нельзя вызывать методы интерфейса напрямую, т.к. они имеют модификатор `private` . Единственный вариант - привести объект класса `MyPrinterExplicit` к типу `IPrinter` и вызвать у него соответствующий метод.

```cs
var mpe = new MyPrinterExplicit();

// Ошибка!
// mpe.PrintToConsole("Hello!");

((IPrinter)mpe).PrintToConsole("Test"); // Test
```

Явная реализация может понадобиться в том случае, если класс реализует два интерфейса, у которых есть методы с одинаковой сигнатурой.

```cs
interface IPrinterV1
{
    void Print(string msg);
}

interface IPrinterV2
{
    void Print(string msg);
}

class ConsolePrinter : IPrinterV1, IPrinterV2
{
    void IPrinterV1.Print(string msg) =>
        Console.WriteLine($"PrinterV1: {msg}");

    void IPrinterV2.Print(string msg) =>
        Console.WriteLine($"PrinterV2: {msg}");
}
```

Демонстрация работы с классом `ConsolePrinter`:

```cs
var cp = new ConsolePrinter();

((IPrinterV1)cp).Print("Test"); // PrinterV1: Test
((IPrinterV2)cp).Print("Test"); // PrinterV2: Test
```

Q: Что такое **неявная реализация интерфейса** в C# и как она выглядит в коде?
A: Это стандартный способ реализации интерфейса, когда методы интерфейса объявляются в классе как **публичные** без указания имени интерфейса.
Пример:
```cs
class MyPrinter : IPrinter {
    public void PrintToConsole(string msg) => Console.WriteLine(msg);
}
```

---

Q: Как вызвать метод интерфейса при **неявной реализации**, если объект объявлен как экземпляр класса?
A: Достаточно вызвать метод напрямую через объект класса, так как метод является публичным:
```cs
var mp = new MyPrinter();
mp.PrintToConsole("Hello!"); // Работает без приведения типов.
```

---
Q: Что такое **явная реализация интерфейса** и в чём её синтаксическая особенность?
A: Это реализация, при которой методы интерфейса объявляются с указанием имени интерфейса и автоматически становятся **приватными**.
Синтаксис:
```cs
void IPrinter.PrintToConsole(string msg) => Console.WriteLine(msg);
```

---
Q: Почему при **явной реализации интерфейса** нельзя вызвать метод напрямую через объект класса?
A: Потому что явная реализация создаёт **приватный метод**, доступный только через приведение объекта к типу интерфейса:
```cs
((IPrinter)mpe).PrintToConsole("Test"); // Работает
mpe.PrintToConsole("Test"); // Ошибка: метод недоступен.
```

---
Q: В каком случае **явная реализация интерфейса** становится необходимой?
A: Когда класс реализует **несколько интерфейсов с методами одинаковой сигнатурой** (имя + параметры), чтобы избежать конфликта имён.
Пример:
```cs
interface IPrinterV1 { void Print(string msg); }
interface IPrinterV2 { void Print(string msg); }
class ConsolePrinter : IPrinterV1, IPrinterV2 {
    void IPrinterV1.Print(string msg) => Console.WriteLine($"V1: {msg}");
    void IPrinterV2.Print(string msg) => Console.WriteLine($"V2: {msg}");
}
```

---
Q: Как вызвать методы интерфейсов с одинаковыми сигнатурами, реализованные явно?
A: Через **приведение объекта к нужному интерфейсу**:
```cs
var cp = new ConsolePrinter();
((IPrinterV1)cp).Print("Test"); // Вызовет IPrinterV1.Print
((IPrinterV2)cp).Print("Test"); // Вызовет IPrinterV2.Print
```

---
Q: Какая разница в видимости методов при **явной** и **неявной** реализации интерфейса?
A:
- **Неявная**: метод публичный, доступен через объект класса и через интерфейс.
- **Явная**: метод приватный, доступен **только** через приведение к интерфейсу.
