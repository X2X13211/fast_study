# Основы объектно-ориентированного программирования в C#

Объектно-ориентированное программирование (ООП) — это парадигма программирования, в которой основными концепциями являются понятия объектов и классов. В C# ООП реализован полностью и является фундаментом языка.

## Классы и объекты

**Класс** — это шаблон или чертеж, по которому создаются объекты. Он определяет состояние (поля, свойства) и поведение (методы), которые будут иметь все объекты этого класса.

**Объект** — это конкретный экземпляр класса, созданный в памяти во время выполнения программы. Каждый объект имеет собственное состояние, но разделяет поведение, определенное в классе.

```csharp
public class Person
{
    public string Name { get; set; }
    public int Age { get; set; }
    
    public void Introduce()
    {
        Console.WriteLine($"Привет, меня зовут {Name}");
    }
}

// Создание объекта
Person person = new Person();
person.Name = "Иван";
person.Introduce();
```

## Три кита ООП

### 1. Инкапсуляция

Инкапсуляция — это сокрытие внутренней реализации класса и предоставление доступа к данным только через публичные методы и свойства. Это защищает данные от некорректного использования извне.

```csharp
public class BankAccount
{
    private decimal balance; // поле доступно только внутри класса
    
    public void Deposit(decimal amount)
    {
        if (amount > 0)
            balance += amount;
    }
    
    public decimal GetBalance()
    {
        return balance; // доступ только для чтения
    }
}
```

Модификаторы доступа в C#:
- `public` — доступно отовсюду
- `private` — доступно только внутри класса
- `protected` — доступно в классе и его наследниках
- `internal` — доступно в пределах сборки

### 2. Наследование

Наследование позволяет создавать новые классы на основе существующих. Дочерний класс получает все поля, свойства и методы родительского класса и может расширять или изменять их функциональность.

```csharp
public class Animal
{
    public string Name { get; set; }
    
    public void Eat()
    {
        Console.WriteLine($"{Name} ест");
    }
}

public class Dog : Animal // Dog наследует Animal
{
    public void Bark()
    {
        Console.WriteLine($"{Name} лает");
    }
}
```

В C# класс может наследовать только от одного базового класса, но может реализовывать множество интерфейсов.

### 3. Полиморфизм

Полиморфизм позволяет объектам разных классов обрабатывать вызовы методов через единый интерфейс. В C# полиморфизм реализуется через виртуальные методы и переопределение.

```csharp
public class Shape
{
    public virtual void Draw()
    {
        Console.WriteLine("Рисуем фигуру");
    }
}

public class Circle : Shape
{
    public override void Draw()
    {
        Console.WriteLine("Рисуем круг");
    }
}

public class Rectangle : Shape
{
    public override void Draw()
    {
        Console.WriteLine("Рисуем прямоугольник");
    }
}

// Использование
Shape[] shapes = { new Circle(), new Rectangle() };
foreach (Shape shape in shapes)
{
    shape.Draw(); // Вызовется метод конкретного класса
}
```

Ключевые слова для полиморфизма:
- `virtual` — метод, который можно переопределить
- `override` — переопределение виртуального метода
- `abstract` — абстрактный метод без реализации (класс тоже должен быть абстрактным)

## Интерфейсы

Интерфейс определяет контракт — набор методов и свойств, которые должен реализовать класс. Класс может реализовывать несколько интерфейсов.

```csharp
public interface IComparable
{
    int CompareTo(object obj);
}

public class Student : IComparable
{
    public string Name { get; set; }
    public int Grade { get; set; }
    
    public int CompareTo(object obj)
    {
        Student other = obj as Student;
        return this.Grade.CompareTo(other.Grade);
    }
}
```

## Абстрактные классы

Абстрактный класс — это класс, который не может быть инстанцирован. Он может содержать как абстрактные методы (без реализации), так и обычные методы с реализацией.

```csharp
public abstract class Vehicle
{
    public abstract void Move(); // абстрактный метод
    
    public void Stop()
    {
        Console.WriteLine("Транспорт остановился");
    }
}

public class Car : Vehicle
{
    public override void Move()
    {
        Console.WriteLine("Машина едет по дороге");
    }
}
```

## Статические члены

Статические поля и методы принадлежат самому классу, а не конкретному объекту. Они доступны без создания экземпляра.

```csharp
public class Counter
{
    public static int Count = 0;
    
    public Counter()
    {
        Count++;
    }
    
    public static void ShowCount()
    {
        Console.WriteLine($"Создано объектов: {Count}");
    }
}
```

## Свойства и автосвойства

Свойства предоставляют механизм для чтения и записи полей с дополнительной логикой. Автосвойства автоматически создают скрытое поле.

```csharp
public class Product
{
    // Автосвойство
    public string Name { get; set; }
    
    // Свойство с логикой
    private decimal price;
    public decimal Price
    {
        get { return price; }
        set 
        { 
            if (value > 0)
                price = value; 
        }
    }
}
```

## Конструкторы

Конструктор — это специальный метод, вызываемый при создании объекта. Он инициализирует начальное состояние объекта.

```csharp
public class Book
{
    public string Title { get; set; }
    public string Author { get; set; }
    
    // Конструктор по умолчанию
    public Book()
    {
        Title = "Неизвестно";
        Author = "Неизвестно";
    }
    
    // Параметризованный конструктор
    public Book(string title, string author)
    {
        Title = title;
        Author = author;
    }
    
    // Конструктор с вызовом другого конструктора
    public Book(string title) : this(title, "Неизвестно")
    {
    }
}
```
